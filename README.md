Relational Database Design

OLTP vs OLAP

Star Schema and Snowflake Schema

Fact Tables and Dimension Tables

Measures, Metrics, and Granularity

Slowly Changing Dimensions (SCD Types 0–6)

Surrogate Keys and Natural Keys

Data Vault Modeling

One-to-One, One-to-Many, and Many-to-Many Relationships

Database Indexing and Constraints

Data Lake and Lakehouse Modeling

Schema Evolution and Versioning

Data Modeling for Data Warehouses

Data Modeling Interview Questions

Real-World Data Modeling Projects
